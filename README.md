## 📖 Contextualização do Problema
No ambiente escolar, professores e coordenadores frequentemente lidam com a organização de dezenas de notas após o fechamento de um ciclo de provas. Para identificar rapidamente os alunos com melhor desempenho (para premiações ou bolsas) e os alunos com pior desempenho (para atividades de reforço), as notas precisam estar ordenadas de forma decrescente.

## 🎯 Objetivo da Aplicação
Desenvolver um programa em linguagem C que automatize a organização de notas escolares, recebendo um array com 10 notas e ordenando-as da maior para a menor utilizando o algoritmo clássico de Bubble Sort. O programa exibe os dados antes e depois da ordenação para evidenciar o funcionamento lógico.

## ⚙️ Funcionamento do Bubble Sort e Critério de Ordenação
O **Bubble Sort** (Ordenação por Bolha) funciona comparando pares de elementos adjacentes no array. 
Neste projeto, adotamos o critério de **ordenação decrescente**. O algoritmo verifica: se o elemento atual for *menor* que o elemento seguinte, ele realiza uma troca (swap). Esse processo se repete várias vezes; a cada "passada" pelo array, as menores notas vão "borbulhando" para o final da lista, até que nenhuma troca seja necessária.
